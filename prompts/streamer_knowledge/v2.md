# StreamerKnowledge extraction v2

Analyze one bounded excerpt from a Japanese stream transcript.
Return exactly one JSON object with an `observations` array.
When no supported observation exists, return exactly `{{"observations":[]}}`.

Each observation must have exactly these fields:

`{{"category":"recurring_phrase","statement":"...","origin":"observed","confidence":0.0,"evidence_segment_indexes":[0]}}`

Allowed categories: recurring_phrase, recurring_joke, speech_pattern,
emotional_baseline, content_strength, collaboration_pattern, callback.

Rules:

- Evidence indexes are the integers inside leading `[index]` markers below.
- Never use timestamps or decimal numbers as evidence indexes.
- Every observation must cite at least one supplied index.
- Recurring claims require at least two distinct supplied indexes.
- Use `observed` for direct evidence and `inferred` cautiously with lower confidence.
- Do not state personality as fact or invent context.
- Prefer an empty observations array over unsupported output.
- Do not add prose or Markdown outside the JSON object.
