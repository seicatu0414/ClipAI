# 実験と評価

ClipAIの不確実なAI挙動は、もっともらしさではなく評価結果で採否を決めます。

主要仮説は、個別知識が汎用検出より採用率を高めること、安価な信号で品質を大きく落とさずLLM負荷を減らせること、15～120秒の可変窓が固定窓より導入とオチを保つこと、◎・○・×が将来順位を改善すること、映像の追加精度が音声・文字起こし基準線の後に費用を正当化することです。

最初は対象配信者数名分の非公開ベンチマークを使い、原本と人が確認した良い・悪い区間を保存します。候補採用率、Precision@20/30、重複率、既知の良場面の網羅、誤検出分類、レビュー時間、動画1時間当たり処理時間、GPUメモリ、LLM利用量、説明品質を測定します。

各実験に仮説、データセット、パイプライン、モデル、プロンプト、設定、指標、定性的失敗、判断を記録します。対象指標の改善、既知の失敗修正、または許容できる品質を保った費用削減がない変更は既定にしません。失敗した実験も保存します。
